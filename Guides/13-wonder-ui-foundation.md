# 桌面、功能区与组件操作

Wonder 的桌面由功能区和组件快捷方式组成。顶栏提供启动器菜单与标准窗口操作；功能区可以添加、拆分、移动或移除。首次启动会放置一个功能区和设置快捷方式，手动清空后的桌面在重启时保持空白。

## 管理功能区

- 在功能区右键菜单选择“左右拆分功能区”或“上下拆分功能区”，可组合横向与纵向布局。顶栏菜单也提供“添加上下功能区”；还可移除功能区、恢复默认布局或清空桌面。
- 长按功能区顶边栏后拖动：目标功能区的上、下、左、右边缘用于重新摆放，将整个来源区插入对应方向；目标区中央用于交换两个整区。默认长按时间为 450 毫秒，可在设置中调整；主体空白处不会启动整区拖动。
- 四周各约 25% 的边缘范围判断摆放方向，中央一半宽、一半高的范围判断交换。角落取按区域宽高归一化后最近的边。拖动中显示最终摆放占位或中央交换预览，并明确提示“放在上方/下方/左侧/右侧”或“交换功能区”；松开时才改变布局。
- 摆放会移动已有功能区、合并原位置空出的分隔，再在目标方向分割放置；不会复制或删除组件，也不会改写各区的中心偏移与应用数据。拖回自身、移到功能区外、Esc 或丢失鼠标捕获都不提交摆放。顶部侧栏仍通过拖动分隔线或右键侧栏菜单收起，与整区摆放独立。
- 拖动两个功能区之间的共享分隔边可调整大小，无需长按。悬停时整条边会高亮。
- 右键功能区或侧边栏，选择“重命名功能区…”。Enter 保存，Esc 或关闭弹窗取消。名称去除首尾空白后须为 1–120 字符的单行文字，允许同名。长标题省略时可悬停查看完整名称。
- 功能区序号默认隐藏，在设置中开启“显示功能区序号”即可显示。
- Esc 可取消正在进行的拖动；取消不会提交新的位置或归属。

## 收起为侧边栏

拖动分隔边，将位于桌面外缘的相邻单个功能区缩至 64 DIP 以下，松开后会收成 28 DIP 的边条。四个方向均支持；缩小窗口本身不会触发收起，包含多个功能区的整组不会自动收起。

也可右键功能区，使用“收起为侧边栏”选择可用方向（左侧、右侧、顶部或底部）；只显示当前布局允许的外缘方向。右键已收起的侧栏可直接“恢复为普通功能区”。上下布局可将顶部区向上收起、底部区向下收起。

悬停边条会展开该区并压缩相邻功能区，默认展开尺寸为 320 DIP；离开后默认等待 280 毫秒收起。这两个值均可在设置中调整。鼠标停在朝内的拖动边缘，或正在拖动组件时，侧栏保持展开。

拖动展开区朝内的一整条边，实际可见尺寸比拖动开始时增加超过 8 DIP 后松开，可恢复为普通功能区。空间不足或未达到条件时，提示会说明松开后保持侧栏；Esc 取消。侧栏内的组件仍可操作、移动或接收组件库拖入的快捷方式。

## 使用组件库

从顶栏菜单或工作区右键菜单打开组件库。它是独立窗口，可与桌面同时操作：

1. 搜索所需组件，直接点击库内入口即可使用应用。
2. 从库内组件或卡片标题拖到功能区，创建快捷方式。拖到空桌面时会创建第一个功能区。
3. 短按桌面快捷方式执行动作；长按后拖动可移动，或放到其他功能区。拖动结束不会额外触发点击。
4. 将桌面组件长按拖回组件库页面并松开，可移除这一处快捷方式。其他快捷方式和应用数据保留。

Windows 与 Linux（X11/XWayland）上，开始拖动后实时预览会置顶跟随指针，包括两个窗口之间。可以把工作区的组件经过组件库再拖回工作区。松开时按落点放置或移除快捷方式，按 Esc 取消。点击下载组件任意位置都可打开下载中心。普通按钮和轮廓按钮在成功点击时显示水波纹。

当前组件包括设置、便笺、启动器状态、实例管理、游戏启动和账户管理。详见[组件使用与状态](16-component-system.md)、[实例管理与启动](18-instance-management-and-launch.md)及[账户管理](26-account-management.md)。

## 位置、显示与保存

每个快捷方式独立保存相对功能区坐标原点的位置；同一应用的多个入口共享应用数据。缩小窗口或功能区不会自动缩放组件，也不会永久改写位置；超出可见区域的部分会裁切。需要重新整理时，使用“整理组件到可见范围”菜单。

右键功能区选择“拖动工作区中心”，显示十字坐标轴。在主体区域按下并拖动即可平移原点和该区的所有组件，无需长按；组件相对原点的位置保持不变。原点超出可见区域时，边缘箭头指向原点。松开保存平移结果；按 Esc 取消本次尚未完成的拖动并退出模式，或右键“结束中心拖动”。“重置工作区中心”将原点放回功能区几何中心，已提交的偏移随布局保存。

“设置 → 个性化设置 → 组件整体大小”统一调整桌面组件的显示比例（50%–200%，默认 100%），文字、图形和命中区域一起缩放，组件中心位置不变。组件库仍使用便于浏览的卡片预览，拖入桌面后使用设定比例。

组件沿自身轮廓响应悬停与点击，透明角不参与命中。组件移动不会触发功能区换位高亮。鼠标按住或跨窗口拖放时，普通悬浮提示暂时隐藏；松开并重新悬停后恢复。成功点击会显示轮廓内的波纹，动作无需等待动画结束。

布局与便笺自动保存在程序旁的 `WonderData`。连续修改约 350 毫秒后合并为后台保存；正常关闭会等待最新内容写完，失败时窗口保持打开并允许重试。损坏文件不会被自动覆盖，详见[数据保存与恢复](15-portable-data-and-motion.md)。
