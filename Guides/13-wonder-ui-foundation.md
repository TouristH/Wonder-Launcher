# 奇想 UI 第一步：框架、功能区与组件

设计日期：2026-10-01。最近修订：2026-10-22。实现范围：可交互的原生桌面 UI 基础。当前组件通过[通用组件系统](16-component-system.md)接入，包含设置、便笺和启动器状态；下方历史验证记录保留当时的事实，不代表仍保留演示组件。

## 依据与边界

根据“重构奇想我的世界启动器”聊天及[产品目标](12-product-goals.md)，工程统一采用 `Wonder` 名称。2026-10-25 已将当前实现落实到本地主目录；解决方案仅包含 Wonder 工程，不恢复前身产品的账号、配置或插件。

本阶段从残存 `ComponentGeometry.cs` 的多边形构造思路和 `ComponentPlacementMath.cs` 的有限数值/边界约束重新建立工作区模型。旧数据迁移、旧组件契约和旧项目文件不进入新工程。

## 已确定的交互

- **框架**：只有启动器信息与标准窗口操作的顶栏；内容全部属于可移除的功能区。无固定侧栏、底栏或业务页面。
- **功能区**：矩形分区组成嵌套横/纵切分布局。仅长按顶边栏约 450 ms 后拖至另一区，交换整区内容；主体空白处不启动换位。共享分隔边整条可选，悬停高亮，按下即可拖动调整相邻区大小。
- **侧边栏**：手动拖动分隔边，将直接相邻且位于框架对应外缘的单个功能区请求尺寸缩至 64 DIP 以下，松开后收为 28 DIP 边条。支持四个方向；悬停按固定厚度参与分区布局，默认 320 DIP，压缩相邻功能区；离开 280 ms 后收起。展开区朝内整边可立即拖动，向内放大超过 8 DIP 后松开恢复普通区。组件操作、跨区移动、库内拖入和中心偏移规则继续适用。仅手动调整触发收起，缩窗不触发；父节点包含多个区时不自动收起整组。
- **组件**：当前只提供设置；三个演示组件已删除。设置保留六边形命中与拖动交互，短按打开窗口，长按移动，拖动释放不额外执行点击。可跨功能区放置；用预览跟随指针，松开时才提交归属与中心偏移，取消不改变快捷方式与位置。
- **组件库**：独立非模态窗口，与工作区同时可见和可用。提供搜索、直接使用应用、跨窗口拖动创建快捷方式；移除独立添加按钮及目标区选择。入口位于顶栏菜单和工作区右键菜单；空框架接收组件后创建第一个功能区。长按功能区组件拖回库页面并松开可移除这处快捷方式，其他快捷方式与应用数据保留。
- **应用与快捷方式**：库内组件是应用，功能区中的组件是快捷方式。所有入口共享应用数据；快捷方式拥有独立 ID 与中心偏移，移除或清空框架不删除应用。关联关系随布局保存；设置内容独立存储，多个入口复用同一个设置窗口。新 Wonder 早期预览中的演示组件会被清除，区域结构保留。
- **高亮**：多边形整面填充和轮廓响应悬停、按下、焦点与拖动选择，透明角不参与点击或组件拖动。组件按下、长按与跨区拖动不触发任何功能区高亮；区域高亮只属于顶边栏发起的功能区换位。
- **坐标**：布局版本 2 使用组件中心相对整个功能区中心的 DIP 偏移，允许负值。缩窗/分区缩放不自动夹取坐标、不缩放组件；超出内容区时只裁切。拖动时限制放置边界；整理到可见范围是显式菜单操作。版本 1 预览布局仅在首次真实排版时转换一次，不能把旧左上角值静默解释为中心偏移。
- **默认布局**：首次启动预放一个工作区和设置快捷方式。用户清空后的空框架在重启时保持空白。
- **功能区序号**：默认隐藏，设置中的“显示功能区序号”可即时开启或关闭，不留空位；配置随设置文件保存。
- **悬浮提示**：全应用统一在鼠标按住时关闭并拦截 ToolTip，功能区、组件和组件库共用规则，操作 UI 提示不受影响。Esc 取消但鼠标仍按住时继续拦截；松开后重新悬停恢复。跨窗口原生拖放期间持续抑制，释放在窗口外时通过下一次鼠标移动恢复状态。
- **功能区改名**：右键功能区或侧边栏选择“重命名功能区…”，弹窗自动全选原名；Enter 保存、Esc 或关闭弹窗取消。名称去除首尾空白后须为 1–120 字符的单行文字，允许同名，区域 ID、组件与位置不变。确认后同步普通标题及侧栏标签并立即保存；长标题省略、悬停查看全名，竖排侧栏按 Unicode 文本元素换行，避免拆散 emoji。
- **编辑入口**：工作区右键菜单及顶栏启动器菜单可打开设置、添加/拆分/移除功能区、添加/移除组件、恢复默认布局、清空和查看操作说明。Esc 取消手势。
- **存储**：全新 Wonder 数据目录，版本化 JSON 保存分区、组件、位置和状态；损坏数据提示错误，不静默覆盖。

## 实施计划

1. `src/Wonder.Workspace`：无 UI 依赖的数据模型、切分计算、多边形算法和布局存储；测试换位保留实例、嵌套切分/删除、最小尺寸、边界、空布局恢复及损坏数据。
2. `src/Wonder.Desktop`：Avalonia 窗口、功能区与组件视图、长按状态机和上下文菜单。先验证短按/长按分离，再覆盖取消与边界。
3. `tests/Wonder.Desktop.Tests`：使用 Avalonia Headless 发送真实指针事件，检查组件点击/拖动、区换位、分隔线缩放、Esc/失焦取消，并渲染截图检查布局。
4. `Wonder.slnx`：仅包含 Wonder 工程；Release 构建、全部新工程测试、发布 Windows 可执行产物，补齐运行与操作说明。

## 验收重点

快速移动不会误触动作；长按松开不会点击；区域交换时组件跟随；拖至框架外可取消；缩窗不永久改写存储位置；保存失败可见；重启保留用户清空状态。

本阶段不宣称已实现游戏安装、认证、启动或第三方插件运行，也不将 UI 样例的动作伪装成实际游戏功能。
