# 设置组件

从桌面设置快捷方式、组件库、顶栏菜单或工作区右键菜单打开设置。多个入口共用同一个窗口；移除快捷方式、清空桌面或关闭设置窗口不会删除设置。

设置窗口分为“启动器设置”“游戏全局设置”“个性化设置”。外观和交互选项修改后立即生效并自动保存；游戏全局设置需要点击保存，供下次启动使用。启动参数继承规则见[分类设置与实例卡片](21-settings-pages-and-instance-cards.md)。

## 外观与交互选项

| 选项 | 默认值 | 可用范围与效果 |
| --- | --- | --- |
| 主题 | 深色 | 跟随系统、深色、浅色；所有窗口统一更新 |
| 强调色 | 薄荷绿 | 薄荷绿、晴空蓝、琥珀金、蔷薇粉 |
| 工作区留白 | 22 DIP | 0–40 DIP，调整桌面四周边距 |
| 显示功能区序号 | 关闭 | 控制标题左侧序号，隐藏后不留占位 |
| 长按拖动时间 | 450 毫秒 | 250–1000 毫秒；分隔边仍可直接拖动 |
| 侧边栏展开尺寸 | 320 DIP | 200–600 DIP；左右为宽度，上下为高度，空间不足时临时缩小显示 |
| 侧边栏收起延迟 | 280 毫秒 | 100–1000 毫秒；拖动期间保持展开 |

调整参数时会取消正在进行的桌面手势。选项与滑块支持键盘操作；窗口较小时可滚动内容，底部保留保存状态与恢复入口。

## 保存失败与恢复

设置保存在 `<程序目录>/WonderData/settings.json`，布局另存为 `workspace.json`。启动时创建数据目录；目录无法写入时显示错误，不自动改用其他目录。设置文件缺失时使用默认值，打开设置窗口本身不会写入文件。

- **无法读取**：保留原文件，以默认值运行并暂时禁用编辑。修复文件后点击“重试”；若选择“恢复默认设置”，需要明确确认覆盖。
- **无法保存**：当前会话内的效果保留，状态显示“尚未保存”。检查目录权限、文件占用和磁盘空间后，点击“重试”保存当前值。
- **恢复默认设置**：恢复外观与交互选项，不清空功能区、删除快捷方式或重置布局，也不清除游戏配置。

保存采用同目录临时文件替换，提交前失败会保留旧设置。不要在启动器运行时直接改写数据文件。便携数据、账户迁移限制和布局保存说明见[数据保存与恢复](15-portable-data-and-motion.md)。
