# 设置组件

从桌面设置快捷方式、组件库、顶栏菜单或工作区右键菜单打开设置。多个入口共用同一个窗口；移除快捷方式、清空桌面或关闭设置窗口不会删除设置。

设置窗口分为“个性化设置”“游戏全局设置”和“启动器设置”，默认打开个性化。外观、交互和下载偏好修改后立即生效并自动保存。游戏全局设置保存后在下次启动游戏时生效。启动参数继承规则见[分类设置与实例卡片](21-settings-pages-and-instance-cards.md)。

## 外观与交互选项

| 选项 | 默认值 | 可用范围与效果 |
| --- | --- | --- |
| 主题 | 深色 | 跟随系统、深色、浅色；所有窗口统一更新 |
| 强调色 | 薄荷绿 | 薄荷绿、晴空蓝、琥珀金、蔷薇粉 |
| 每日首次启动显示 Logo | 开启 | 按本机日期，每天首次打开时在进入桌面前居中播放大彗星 Logo 动画，使用已保存的明暗主题和强调色；关闭后直接进入桌面 |
| 开场动画样式 | A · 停稳闪星 | 可选择 A · 停稳闪星或 B · 碎星剥落；“对比预览”可并排播放、重新播放和保存选择 |
| 工作区留白 | 22 DIP | 0–40 DIP，调整桌面四周边距 |
| 组件整体大小 | 100% | 50%–200%，统一缩放桌面组件的图形、文字和命中区域，保持中心位置；组件库卡片保持浏览尺寸 |
| 组件网格对齐 | 关闭 | 拖放时以功能区原点为基准，按缩放后的 20 DIP 单位吸附组件边缘；不绘制网格线，已有位置不自动重排，声明自由拖动的插件不吸附 |
| 显示功能区序号 | 关闭 | 控制标题左侧序号，隐藏后不留占位 |
| 长按拖动时间 | 150 毫秒 | 40–250 毫秒，每档 10 毫秒，适用于组件与功能区拖动。分隔边可直接拖动 |
| 侧边栏展开尺寸 | 320 DIP | 200–600 DIP；左右为宽度，上下为高度，空间不足时临时缩小显示 |
| 侧边栏收起延迟 | 280 毫秒 | 100–1000 毫秒；拖动期间保持展开 |

切换明暗主题或强调色时，界面星芒与所有已打开窗口的图标同步更新，新开的窗口直接使用当前配色。采用窗口图标的任务栏项也会更新；EXE 文件、固定快捷方式和桌面启动项的静态图标仍使用随程序发行的资源。

每日 Logo 开场中，小彗星从左上沿原有尾迹向右下旋转飞近，逐渐放大至主彗星的位置。提供两种小星星演出方式：

- **A · 停稳闪星**：飞行时没有周围小星星，主彗星停稳后，小星星依次闪亮并定格成完整 Logo。
- **B · 碎星剥落**：飞行过程中，小星星从主彗星依次分离，沿弧线远离并缩小，最后落在原 Logo 的小星星位置。

两版最终都显示原始完整 Logo，再淡出进入桌面；全过程约 2.4 秒，严格限制在中央 280×280 DIP 正方形内。“对比预览”以当前主题色并排播放两版，可随时“重新播放”，点击某一版的“使用此动画”即可保存选择。只预览或关闭预览窗不会改变样式，也不会更新每日播放日期；关闭每日开场后仍可手动预览。

账户、实例与插件仍会在后台加载。同一份便携设置记录上次显示的本机日期，当天再次启动直接进入桌面；不同便携目录分别记录。在“设置 → 个性化设置”关闭“每日首次启动显示 Logo”即可停用开场。设置无法读取时跳过开场，保留原文件并沿用设置错误提示。

调整参数时会取消正在进行的桌面手势。选项与滑块支持键盘操作；窗口较小时可滚动内容，底部保留保存状态与恢复入口。升级后，旧设置中的 251–1000 毫秒按 250 毫秒生效，并在下次保存设置时写入。

## 保存失败与恢复

设置保存在 `<程序目录>/WonderData/settings.json`，布局另存为 `workspace.json`。启动时创建数据目录；目录无法写入时显示错误，不自动改用其他目录。设置文件缺失时使用默认值，打开设置窗口本身不会写入文件。

- **无法读取**：保留原文件，以默认值运行并暂时禁用编辑。修复文件后点击“重试”；若选择“恢复默认设置”，需要明确确认覆盖。
- **无法保存**：当前会话内的效果保留，状态显示“尚未保存”。检查目录权限、文件占用和磁盘空间后，点击“重试”保存当前值。
- **恢复默认设置**：恢复外观与交互选项，不清空功能区、删除快捷方式或重置布局，也不清除游戏配置。

保存采用同目录临时文件替换，提交前失败会保留旧设置。不要在启动器运行时直接改写数据文件。便携数据、账户迁移限制和布局保存说明见[数据保存与恢复](15-portable-data-and-motion.md)。

在 **设置 → 启动器设置** 选择游戏下载源、并发数和重试次数。下载源影响受支持文件的传输，版本清单和校验信息始终从官方端点读取。配置方式见[下载帮助](33-download-center.md)。
