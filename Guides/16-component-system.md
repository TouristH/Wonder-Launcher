# 组件、快捷方式与状态

组件库中的应用负责功能与数据，桌面中的组件是它的快捷方式。同一应用的库内入口和所有快捷方式共享状态，每个快捷方式独立保存位置。移除快捷方式、清空桌面或关闭组件库，不会删除应用数据。

## 内置组件

| 组件 | 用法 |
| --- | --- |
| 设置 | 打开共用设置窗口，调整外观、交互与游戏全局设置 |
| 便笺 | 直接输入文字；多个入口立即同步 |
| 启动器状态 | 查看版本、运行环境、数据位置和运行时长 |
| 实例管理 | 登记游戏目录、选择实例、修改启动设置与管理目录 |
| 游戏启动 | 启动当前目标，查看运行状态和日志，取消准备 |
| 账户管理 | 管理微软、第三方和离线账户，切换启动身份 |

在组件库中搜索并直接使用应用，或拖到功能区创建快捷方式。长按桌面组件可移动，拖回组件库页面并松开可移除这一处快捷方式。详细操作见[桌面与功能区](13-wonder-ui-foundation.md)。

## 便笺与自动保存

便笺的文字编辑、选择和滚动不会触发桌面长按拖动；需要移动便笺时，使用标题区域。多个入口即时共享文字，连续编辑约 350 毫秒没有新输入后合并为后台保存。

正常关闭会等待最新布局和文字写完。写入失败时保留当前会话内容，窗口保持打开并显示错误，恢复写入条件后可重试。强制结束进程或断电可能丢失未保存内容，详见[数据保存与恢复](15-portable-data-and-motion.md)。

## 隐藏、关闭与异常

没有可见入口时，组件的定时显示活动会暂停，再次显示后恢复。例如，启动器状态不在隐藏时持续刷新运行时长。拖动预览不会启动新的业务任务。

正在准备或运行的游戏不因组件隐藏或快捷方式移除而结束；关闭启动器也不强制结束游戏，但退出后不再监控游戏进程。需要取消启动准备时，使用游戏启动组件中的取消操作。

组件加载或操作失败时显示可重试的占位，不影响其他组件。遇到当前版本无法识别的组件时，布局中保留其信息、状态和快捷方式，并标明不可用；读取失败不会自动覆盖原布局。用户清空后的桌面不会因为组件初始化而重新补入快捷方式。

当前提供内置组件；完整第三方插件运行、安装管理、权限隔离、组件尺寸调整以及布局撤销/重做尚未提供。
