# 0.5.0 分类设置与实例卡片

日期：2026-10-24。按用户提出的设置分类、统一设计语言、加载器版本展示和实例排列切换进行改造。

## 分类设置

设置窗口使用左侧分类按钮和右侧内容页，分为启动器设置、游戏全局设置、个性化设置。保留主题、强调色、工作区留白、功能区序号、长按时间、侧栏尺寸及延迟等现有功能。

外观与启动器交互选项保持修改即应用、自动保存。游戏全局设置使用明确的保存操作，可集中指定 Java、内存、窗口和额外启动参数。实例游戏目录仍由各实例管理，避免多个实例意外共享存档目录。

启动配置按以下顺序叠加，后者优先：

1. Wonder 内置默认值。
2. 从原启动器读取的实例配置。
3. 用户在 Wonder 保存的游戏全局偏好。
4. 用户在该实例中保存的覆盖值。

空白项表示不覆盖前一层，额外参数的“清空”表示显式覆盖为空。游戏全局配置保存在 `WonderData/instances.json` 的 `globalSettings`；旧文件没有此字段时默认不覆盖。实例的有效设置、启动计划和重新打开后的显示使用相同合并规则。保存失败保留已保存配置，不改写来源启动器配置。

## 实例与目录按钮

首页仍是左侧游戏根目录、右侧该目录中的实例。每个目录和实例都是独立按钮，沿用桌面组件的圆角、描边、表面颜色和强调色；悬停、按下、选中和键盘焦点有明确反馈。

实例列表右上角可切换“列表 / 网格”：列表使用占满内容宽度的长条卡片，纵向排列；网格使用方形卡片，按窗口宽度自动调整列数。切换不改变启动目标或清除实例草稿。排列偏好自动保存在 `WonderData/settings.json`，重新打开窗口和重启后沿用；旧设置文件默认使用网格，读取时不改写原文件。

卡片按名称、Minecraft/加载器版本、来源与路径分层显示。长名称与路径截断时，悬停可读完整文字。Tab 和 Enter 可选择并打开实例。根目录切换不改变当前启动目标；打开子实例才切换目标并进入详情。详情表单分为实例信息、Java 与内存、游戏窗口及高级启动参数，固定保存区保持可见。

## 加载器版本

版本摘要展示 Minecraft 核心版本及本地元数据中声明的加载器版本，覆盖 Fabric、Quilt、Forge、NeoForge；有对应元数据时也展示 OptiFine。OptiFine 是附加组件，展示它不表示把它等同于模组加载器。

信息来自版本 JSON 的依赖、继承链，以及 Prism/MultiMC 的组件清单，而不是猜测用户的文件夹名称。旧索引加载时只补全显示信息，不重命名实例或修改游戏文件。展示元数据不等于验证所有相关 JAR 的完整性；启动前继续执行依赖检查。
