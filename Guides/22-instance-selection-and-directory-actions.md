# 实例选择与目录操作

## 选择和编辑

实例管理负责浏览、选择与设置。点击实例卡片会选中启动目标并高亮，停留在列表；右侧“设置”按钮打开该实例详情，不改变启动目标。启动游戏组件使用当前目标和所选账户。列表或网格排列不会改变这个规则。

## 移动或重命名目录

目录卡片的设置入口使用父目录路径和目录昵称（实际文件夹名）确定目标，会实际移动或重命名文件夹，并同步 Wonder 登记。

当前支持 Windows 下同一磁盘内的移动与重命名。跨磁盘移动、网络路径、链接目录、系统目录、用户主目录及无法确认的游戏根目录会被拒绝。涉及运行中实例、共享依赖或操作前路径发生变化时，也会停止并说明原因。

移动后保留实例 ID、自定义名称和覆盖设置，重新读取来源时按移动记录调整相关绝对路径。其他启动器的配置文件内容不变，在原启动器中继续使用时可能需要自行修正旧路径。若目录已经移动但 Wonder 索引写入失败，会尝试移回原位置。

## 删除与回收站

实例与游戏目录均提供“删除”。确认窗口会显示名称、完整路径和操作范围，必须精确输入小写 `sure` 才执行；取消、空值或其他大小写均不执行。

删除使用 Windows 系统回收站。无法回收时会报告失败，不会改为永久删除。请区分“删除”与仅清理 Wonder 条目的“移除登记”。

- 实例删除只针对可安全确定的独立目录，不会把共享游戏根目录当作实例目录。
- 仍被其他实例使用的版本、目录或共享依赖不能回收；运行中实例也不能执行文件操作。
- 独立实例目录之外的共享资源和存档目录保持原样，确认窗口会说明范围。
- 删除最后一个实例后，空目录卡片仍保留，可重新扫描、改名或单独回收整个目录；删除目录本身才移除该目录登记。

若已移入回收站但索引保存失败，Wonder 会保留原登记并阻止进一步修改，提示先从系统回收站还原。处理错误后再继续操作，避免登记与实际文件不一致。

更多实例配置与刷新说明见[实例管理与启动](18-instance-management-and-launch.md)。
