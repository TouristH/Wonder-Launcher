# 账户中心完善计划

2026-10-26。用户明确要求 HMCL 级别的完整账户管理，并选择加入正版皮肤与披风管理。此前基础表单不符合这一体验要求。

## 目标与取舍

使用现有 Avalonia / Wonder 组件架构独立实现账户中心。参考 HMCL 的账户列表、头像、刷新、皮肤操作、UUID 复制、认证服务器发现与管理，不复制 HMCL 代码或资源。保留现有加密账户库、账户类型、启动门禁与用户 WonderData。

普通玩家不填写 Application ID：使用 Wonder 内置公开 ID `fab70daf-af0d-423d-9468-6b42edce3c81`，去除登录页的开发者配置；继续采用现有官方设备授权，自动打开官方页面、提供复制设备码/再次打开/取消和步骤反馈。

账户中心以账户卡片和详情为主，添加账户是独立流程；支持筛选、选中状态、UUID/来源/最后验证时间、刷新、重新登录、删除确认与离线改名。失效账户保留条目并提示重新登录，不自动降级。

自定义 Yggdrasil：先发现服务器元数据，再由玩家确认实际 API 地址、保存服务器；可重命名/移除。服务器正在被账户使用时禁止直接移除。第一次第三方启动从 authlib-injector 官方端点自动准备 JAR，校验官方 SHA-256、限制来源与大小、原子写入，后续验证缓存；高级手动 JAR 兼容保留在服务层。

正版外观：读取当前皮肤与自有披风，显示角色正/背面预览；选择 PNG 后预览，明确选择经典/纤细模型并点击上传。支持恢复默认皮肤、选择/隐藏拥有的披风。实际上传/切换只在用户明确操作时发出；浏览或预览不修改远端。只向固定 Minecraft Services 地址发送正版令牌；纹理下载不带令牌。

本轮不包含离线游戏内自定义皮肤（用户选择正版外观管理）。不能把预览冒充游戏内生效。AppID 授权和真实服务验收不由合成测试证明。
