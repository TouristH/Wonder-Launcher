# Wonder 品牌资产

本目录是 Wonder Launcher 自己的标志资源，不属于任何第三方。

| 文件 | 用途 |
|---|---|
| `wonder-mark.svg` | 48–256 px 使用的细版：浅色尾迹、亮芯、三颗碎星 |
| `wonder-mark-small.svg` | 16–32 px 使用的简版：加粗星芒与短尾，去掉渐变与碎星 |
| `wonder.ico` | 7 个尺寸（16/24/32/48/64/128/256）合成的应用图标，16–32 用简版，48 起用细版 |
| `wonder-mark-256.png` | 单个 256 px 位图，便于外部引用 |

几何一致性的来源是仓库里的两个生成器脚本所依据的同一组参数（见 Git 历史）；界面内的标志由 `src/Wonder.Desktop/WonderMark.cs` 用当前强调色实时绘制，与本目录的位图不共享代码路径，但形状一致。
