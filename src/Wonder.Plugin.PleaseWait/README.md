# 请稍候 · 0.3.0

Wonder API 2 插件，提供五个场景组件、随真实操作变化的单行字幕、依次淡入、可滚动的出勤表、文字记忆与会话计时。开幕三分钟剧情、Minecraft 关卡及后续 Meta 流程仍在开发。

在插件管理中安装并启用后，解说条、出勤表、工具面板、记录本、实例列表首次按此顺序出现，间隔 300ms，每个用 180ms 淡入并从下方 4px 浮起。宿主在所在功能区安排初始位置；拖动后记住位置，关闭后可从组件库重新添加，也可以拖回组件库回收快捷方式。重新启用和恢复布局不会重排已有位置或重播初次出现动画。

五个组件默认有 60ms 跟随延迟、最多 ±6° 倾斜，释放时停在原地；启动器开启网格对齐也不会吸附它们。出勤表和带操作行的实例列表从标题区拖动，正文滚轮、滚动条和实例行点击用于各自的交互。

| 组件 | 本阶段内容与尺寸 |
|---|---|
| 解说条 | 所在功能区宽度减两侧各 24，高 56；单行省略文字和 4 秒呼吸指示点 |
| 出勤表 | 220×180；标题固定，正文与最多 64 条近期行为在内部滚动 |
| 工具面板 | 200×132；四个能力名称及右侧暗色状态点 |
| 记录本 | 200×140；空白记录区与底部右侧「第 1 天」 |
| 实例列表 | 320×120；琥珀标记的「请稍候」施工中条目，点击会说明关卡尚未接入 |

关闭「显示观测读数」后，出勤表恢复 220×96，解说条和其它场景组件保留。宿主未提供观测 API 时仅提供这张基础出勤表。

## 真实字幕

解说条先亮起指示点 200ms，再用 180ms 整句淡入「玩家打开了启动器。」；没有逐字打字或配音。之后从真实操作选择一句字幕，当前支持鼠标按键、滚动、快捷键、文字输入发生、组件与功能区拖动、窗口变化和实例选择。

光标移动时立即清空旧句，持续移动期间保持安静；静止 1 秒后才描述其在当前启动器窗口内的方位与停留时间。新操作打断时没有淡出，至少等待 300ms 再改口；同类句子 8 秒内不重复。普通句子结束用 120ms 淡出。没有可靠观察数据时清空字幕，未观测到的桌面位置和 Minecraft 运行情况不会被编成台词。

## 配置

启动器自动生成当前数据目录下的 `plugin-data/wonder.please-wait/config.json`。在插件管理中选择「修改配置」，可以用开关和数字输入框编辑以下参数，也可切换到 JSON 编辑。保存后正在运行的插件会重新启用并应用新值。

| 参数 | 默认值 | 范围与效果 |
|---|---|---|
| `showObservations` | `true` | 显示观测读数；设为 `false` 后仍记录会话时长 |
| `dragDelayMilliseconds` | `60` | 0–200 毫秒；0 表示立即跟随 |
| `maximumDragTiltDegrees` | `6` | 0–6 度；0 表示不倾斜 |

配置不符合类型或范围要求时，启动器会保留原文件并提示修正。剧情文字和会话记录在独立的 `state.json` 中。

## 文字与上一句

文字位于当前启动器数据目录的 `plugin-data/wonder.please-wait/state.json`。初次内容：

```json
{
  "step": 1,
  "text": "测试"
}
```

卡片首次实际显示后，文件增加 `lastDisplayedText`。修改 `text`，保存文件，重启启动器或停用后重新启用插件：正文显示新文字，底部显示「上次：」及上次实际显示的文字。第一次没有上一句。组件库预览不推进记忆，多视图共享同一次启用的上一句。

`state.json` 使用 UTF-8 无 BOM、两空格缩进和 LF 换行。`step` 和自加字段会保留。显示文字只在启用时读取，没有实时监听；首次显示保存上一句、停用时保存会话都会重新读取文件并合并现有修改。JSON 或已知字段无效时显示错误，原文件保留供修正。

## 真实观测与会话

卡片可见时每 50ms 更新：启动器内的光标坐标、静止时长、所选实例、距上次关闭的时间、离开时长档位、时钟调整提示、最近五次点击与最多 64 条近期行为。点击包含左、右、中和侧键；行为包含滚动、快捷键、功能键、文字输入发生、菜单、窗口、拖放以及组件和功能区的语义操作。两组记录从新到旧排列，亮 600ms 后变灰并保留，较早行可通过滚轮或滚动条查看。鼠标静止不到 0.5 秒显示 `0.0 秒`，之后显示完整静止时长；移动就归零。没有可用光标位置时显示「未观测」，没有所选实例时显示「未选择」。

这些读数覆盖启动器主窗口、所属窗口和菜单，不限于功能区；不读取其它应用、全局桌面或输入文字内容。近期行为仅保留在内存中，不写入 `state.json`。实例一项表示当前选择的实例，不表示 Minecraft 进程正在运行。

停用插件或正常关闭启动器时，`sessions` 增加一条记录，`lastSeenUtc` 更新为关闭时间，例如：

```json
{
  "step": 1,
  "text": "测试",
  "lastDisplayedText": "测试",
  "sessions": [
    {"start":"2026-11-14T00:22Z","minutes":2}
  ],
  "lastSeenUtc": "2026-11-14T00:24:00.0000000+00:00"
}
```

每条会话独占一行；`start` 为 UTC、精确到分钟，`minutes` 为本次启用期间的完整分钟数。计时采用单调时钟，修改系统时间不会增加会话分钟数。发现系统时间跳变时显示「已调整」，并在该会话中附加 `"clockAdjusted": true`。修改配置会重新启用插件，因此也会结束上一条会话。宿主未提供观测 API 时不写入会话记录。

首次启用显示「首次」、档位 1；以后按距上次关闭的时间分为五档：少于 2 小时为 1，2 小时至不足 1 天为 2，1 天至不足 7 天为 3，7–30 天为 4，超过 30 天为 5。少于 2 小时统一显示「2 小时内」，1 天起显示整天数，超过 30 天显示按 30 天计算的整月数。

本阶段不需要 Minecraft、Java、网络或账号。源码只引用 `Wonder.Extensibility.Contracts`，组件外观与拖动由启动器通过通用 API 呈现。
